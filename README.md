# أوامر التوزيع

برنامج ويب لإدارة أوامر التوزيع وصرف الكميات على المناطق. يعمل على الآيفون والكمبيوتر من نفس الرابط.

## المزايا
- حسابان: المدير والمستخدم، مع صلاحيات للمستخدم يحددها المدير.
- أوامر توزيع بعدة أصناف (رقم الصنف 11 رقماً يبدأ بـ 22).
- صرف على دفعات لكل منطقة، مع سجل تفصيلي والمتبقي بعد كل صرف، والتراجع عن الصرف.
- الأوامر المنتهية محفوظة في سجل مستقل.
- تصدير Excel، وطباعة، ونسخ احتياطي واستعادة.
- تواريخ هجرية (أم القرى) أو ميلادية.

## التقنية
- صفحة واحدة `index.html` تُستضاف على GitHub Pages.
- البيانات وتسجيل الدخول على Firebase (Firestore + Authentication).
- قواعد الحماية في `firestore.rules`، وتُنسخ يدوياً إلى Firebase Console ← Firestore ← Rules.

## النسخة المحلية (بدون إنترنت)
- `index-local.html` ملف واحد يعمل على جهاز واحد بدون إنترنت ولا مزامنة، والبيانات محفوظة في IndexedDB داخل المتصفح.
- يُولَّد من `index.html` بالأمر `node tools/build-local.js`، ويجب إعادة تشغيله بعد أي تعديل على `index.html`.
- الرقم السري الافتراضي للحسابين عند أول تشغيل `000000`.
- البيانات مرتبطة بالمتصفح ومكان الملف، فافتحه دائماً من المكان نفسه وبالمتصفح نفسه، وخذ نسخة احتياطية بانتظام.
- تُنزَّل النسخة المحلية من الإعدادات ← «النسخة المحلية» في البرنامج، والزر يعمل فقط إذا كان `index-local.html` بجانب `index.html` في المستودع.

### بعد كل تعديل على `index.html`
1. شغّل `node tools/build-local.js` لتحديث `index-local.html`.
2. ارفع الملفين `index.html` و `index-local.html` معاً.
3. إذا كانت النسخة المحلية مرفقة في صفحة Releases، فارفع النسخة الجديدة هناك أيضاً.
