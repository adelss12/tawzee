# أوامر التوزيع

برنامج ويب لإدارة أوامر التوزيع وصرف الكميات على المناطق. يعمل على الآيفون والكمبيوتر من نفس الرابط.

## المزايا
- حسابان: المدير والمستخدم، مع صلاحيات للمستخدم يحددها المدير.
- أوامر توزيع بعدة أصناف (رقم الصنف 11 رقماً يبدأ بـ 22).
- صرف على دفعات لكل منطقة، مع سجل تفصيلي والمتبقي بعد كل صرف، والتراجع عن الصرف.
- الأوامر المنتهية محفوظة في سجل مستقل.
- تصدير Excel، وطباعة، ونسخ احتياطي واستعادة.
- تواريخ هجرية (أم القرى) أو ميلادية.

## التقنية
- صفحة واحدة `index.html` تُستضاف على GitHub Pages.
- البيانات وتسجيل الدخول على Firebase (Firestore + Authentication).
- قواعد الحماية في `firestore.rules`، وتُنسخ يدوياً إلى Firebase Console ← Firestore ← Rules.
